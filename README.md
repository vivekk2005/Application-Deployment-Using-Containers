# Podman Nginx Container Deployment

## 📌 Project Overview
This project demonstrates deployment of an Nginx web server using Podman containers with persistent storage and systemd auto-start.

## 🌐 Access
http://localhost:8080

## 🚀 Features
- Containerized Nginx deployment using Podman
- Host directory mounted as volume
- Real-time update reflection
- Systemd service for auto-start on boot
- Data persistence after container removal and reboot

## 🛠️ Technologies Used
- Podman
- Nginx
- Linux
- Systemd

## ⚙️ Steps Performed
1. Set custom shell prompt using registration number (`12319700`)
2. Created web content directory
3. Deployed Nginx container with volume mount
4. Configured SELinux permissions
5. Generated systemd service file
6. Enabled container auto-start
7. Verified persistence after reboot
